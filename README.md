# Система поддержки клинического рассуждения

Сейчас готовы М1 (схема и хранилище) и М2 (приём документов и опросников).

## Запуск

```sh
docker compose up -d --build
```

- Веб-интерфейс: http://localhost:5173
- API и документация: http://localhost:8000/docs
- Postgres: `localhost:55440` (порт меняется переменной `DB_PORT`)

При старте API применяет миграции и загружает справочник из `content/`.

## Как пользоваться

1. «Загрузить файлы» → код пациента, класс данных, файлы (медкарты, выписки, транскрипты бесед, таблицы опросников).
2. Тип файла определяется по имени (`content/file_rules.csv`), выписки режутся на визиты по строкам `ГГГГММДД_Специальность`.
3. Дата документа берётся из строки визита, из имени файла (`беседа 2025-10-20.txt`, `беседа 20.10.2025.txt`) или из первых строк текста. Если её нет, отчёт после загрузки предложит указать дату. Позже её можно поправить в карточке документа.
4. Если файл с таким именем уже загружен, а содержимое другое, интерфейс спросит: это исправленная версия или другой документ.
5. Любая правка создаёт новую версию документа; прежние версии и журнал действий видны на вкладке «История».
6. Если загружен не тот файл, на вкладке «Файлы» его можно отозвать целиком (со всеми полученными документами и измерениями) и при необходимости вернуть. Безвозвратное удаление — для данных, которые не должны храниться в карте, например файла другого человека; требует причину и ввод имени файла.

## Разработка

Бэкенд:

```sh
cd backend
python -m venv .venv && .venv/Scripts/pip install -e ".[dev]"
.venv/Scripts/alembic upgrade head
.venv/Scripts/python -m app.cli load-content
.venv/Scripts/python -m app.cli ingest "../sample/Пациент Х/Пациент Х" --patient-code X --alias Х --data-class deidentified
.venv/Scripts/python -m app.cli validate X          # проверка SHACL
.venv/Scripts/python -m app.cli export-rdf X -o x.ttl
.venv/Scripts/uvicorn app.api.main:app --reload
```

Фронтенд (React 19, Mantine 9, react-router, TanStack Query):

```sh
cd frontend
npm install
npm run dev            # http://localhost:5173, запросы /api уходят на localhost:8000 (или API_URL)
```

```text
frontend/src/
  api/          типы, запросы, хуки TanStack Query
  components/   общий макет, список пациентов, замечания
  features/
    documents/  список документов, карточка, правка даты и вида
    measurements/ опросники
    files/      исходные файлы: отзыв, возврат, удаление
    history/    журнал приёмов, правок, отзывов и удалений
    upload/     окно загрузки, отчёт, ввод недостающих дат
  pages/        страница пациента, главная, 404
  lib/          форматирование дат, вспомогательные функции
```

## Содержание (`content/`)

Все клинические понятия хранятся в таблицах, а не в коде.

| Файл | Что задаёт |
|---|---|
| `vocabulary.csv` | справочник: классы данных, статусы, виды документов, специальности, виды фрагментов |
| `file_rules.csv` | как распознать файл по имени и как его резать |
| `header_rules.csv` | строка визита в выписках → вид документа и специальность |
| `instruments.csv`, `instrument_items.csv`, `answer_scales.csv` | опросники: пункты, шкала ответов, баллы |
| `table_columns.csv` | служебные колонки таблиц опросников |

После правки таблиц выполните `python -m app.cli load-content` (или перезапустите `api`). Ошибка в таблице указывает файл и строку.
